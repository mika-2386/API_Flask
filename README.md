# Это проект для работы с csv файлами

1. скачайте себе данный проект 
2. Переходите в корень проекта устанавливаете venv, pip-tools 
3. переходите в (venv)
4. устанавливаете зависимости (pip-compile.exe и pip-sync.exe)
5. запускаете проект flask --app .\acme\server.py run
6. переходите по ссылке http://127.0.0.1:5000
7. можно подгрузить файл с расширением .csv, .xlsx, .xls
8. можно загрузить таблицу .csv из базы (не забудьте ввести свои данные для БД в .env).
9. воспользуйтесь отчисткой данных после загрузки таблицы "Очистить данные"
10. После того как таблица скорректировалась - результат можно сохранить в БД. Для этого 
ввойти в свою БД. В вполе ввести название таблицы и нажать "Сохранить в БД"
11. Выберите колонку по которой хотите провести анализ. 
12. Запустить анализ, ниже выведет результат анализа. Для каждо таблицы выводиться свой результат
13. Для построения графика выберите колонки по которым хотите сторить. Нажмите "Отобразить график"
14. так же можно подключиться к своей БД и повторить п.9-10.
