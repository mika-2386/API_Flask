# Это проект для работы с csv файлами

1. скачайте себе данный проект 
2. Переходите в корень проекта устанавливаете venv, pip-tools 
3. переходите в (venv)
4. устанавливаете зависимости (pip-compile.exe и pip-sync.exe)
5. запускаете проект flask --app .\acme\server.py run
6. переходите по ссылке http://127.0.0.1:5000
7. можно подгрузить файл с расширением .csv
8. можно сформировать из базы (не забудьте ввести свои данные для БД).
9. воспользуйтесь отчисткой данных после загрузки таблицы
9. Выберите колонку по которой хотите провести анализ
10. Запустить анализ, ниже выведет результат анализа
10. Для построения графика нажать отобразить график - построит график на отдельной странице
11. так же можно подключиться к своей БД и повторить п.9-10.
